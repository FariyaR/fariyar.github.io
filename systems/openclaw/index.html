System 04

OpenClaw Analytics Agent

Reads the marketing numbers every morning, reports in Slack. Claude reasoning over 4 live integrations, deployed on a hardened EU server, posting a plain-language digest to Slack on schedule.

4live integrations, 24/7
Hover a step for what it does

Text version: GA4 · Meta · Google Ads · Kajabi → Reason → Write → Slack

Problem

The team had GA4, Meta, Google Ads and Kajabi data but nobody had time to read all four every day.

What I built

An agent with MCP tools over the four APIs, running on a hardened Hetzner VPS (key-only SSH, dual firewall, fail2ban, loopback-only services) for EU data residency, delivering to Slack.

Key engineering decisions

  • EU-resident infrastructure chosen over a managed US host for data-residency reasons.
  • Non-expiring auth flows so the agent never silently stops after a token refresh.
  • Narrative output, not dashboards: the digest says what changed and what to look at.

Validation and QA

Runs unattended 24/7 with logged tool calls; every number in the digest links back to the source metric.

Result

4 integrations, one morning message the team actually reads, no one logging into four dashboards.
